# Reference — Configuration

Every tunable in OmegaClaw is declared as `(= (name) (empty))` and later bound by a `configure` call inside an `init*` function. `configure` lives in `src/config.metta`:

```metta
(= (configure $key $default)
   (let $value (configGetByKey $key $default)
     (add-atom &self (= ($key) $value))))
```

`configGetByKey` calls into `src/config.py`, which resolves the value from four sources, in order:

1. **Command line** — `key=value` pairs on the MeTTa command line.
2. **Environment** — a variable named `OMEGACLAW_<key>`.
3. **Configuration file** — [`config/config.yaml`](/config/config.yaml), or the file named by the `config` parameter.
4. **The default** passed to `configure`.

Three properties of the resolution are easy to trip over:

- **The first value resolved for a key is cached for the lifetime of the process**, including the case where the value came from the default. A parameter that is read before the configuration file is loaded keeps the default forever.
- **If the same key appears more than once on the command line, the last occurrence wins.** This is how an argument appended after the ones generated by `entrypoint.sh` takes effect.
- **Inside the Docker image the environment level does nothing.** `entrypoint.sh` re-execs the agent through `env -i` with a fixed allowlist of sixteen names, and `OMEGACLAW_DIR` is the only `OMEGACLAW_`-prefixed entry on it. In a container, override parameters on the command line or with a mounted configuration file.

`initConfig` runs first in the startup sequence and loads the configuration file; it also drops the cache, so the file is read exactly once per process.

## General (`src/loop.metta`, `initLoop`)

| Parameter | Default | Meaning |
|---|---|---|
| `maxNewInputLoops` | 50 | How many turns the agent keeps running after a new human message before idling. |
| `maxWakeLoops` | 1 | Extra turns granted on each scheduled wake-up. |
| `spamShield` | `False` | Deprecated. When enabled, injects a `DO NOT RE-SEND OR SPAM!` marker into turns with no new input. |
| `sleepInterval` | 1 (seconds) | Delay between loop iterations. Cannot be supplied on the command line — the value arrives as an atom and `sleep/1` rejects it. Use the configuration file. |
| `model` | *(unset)* | Model identifier. When set, it overrides every provider-specific `*_model` key below. |
| `provider` | `Anthropic` | LLM provider. See [Providers](#providers). |
| `maxOutputToken` | 6000 | Output cap passed to the provider. |
| `reasoningMode` | `medium` | Reasoning-effort hint. Only the `OpenAI` provider forwards it to the request body; `OpenRouter` loses it, and `ASIOne` sends a fixed `thinking_budget` instead. |
| `wakeupInterval` | 600 (seconds) | How long idle before the next scheduled wake-up. |
| `logConfigPath` | `""` | Path to a Python [logging configuration file](https://docs.python.org/3/library/logging.config.html#configuration-file-format). |
| `memoryDirectory` | `./` | Working directory for memory files. The container passes an absolute path; leaving it relative makes the agent write into a directory it cannot write to. |
| `config` | *(unset)* | Path to the configuration file itself. |

| `embeddingprovider` | `Local` | `Local` (a model bundled into the image) or `OpenAI` (requires `OPENAI_API_KEY`). |

## Channels (`src/channels.metta`, `initChannels`)

| Parameter | Default | Meaning |
|---|---|---|
| `commchannel` | `irc` | Which registered channel to start: `irc`, `telegram`, `slack`, `mattermost`, `websocket`, `test`. |
| `IRC_channel` | `##omegaclaw` | IRC channel to join. |
| `IRC_server` | `irc.quakenet.org` | IRC server hostname. |
| `IRC_port` | 6667 | IRC port. |
| `IRC_user` | `omegaclaw` | IRC nickname. |
| `MM_URL` | `https://chat.singularitynet.io` | Mattermost base URL. |
| `MM_CHANNEL_ID` | `8fjrmabjx7gupy7e5kjznpt5qh` | Mattermost channel ID. |
| `SL_CHANNEL_ID` | `""` | Slack channel ID. Empty means auto-bind on the first successful auth message. |
| `SL_POLL_INTERVAL` | 60 (seconds) | Slack polling interval. The value is clamped with `min(60, …)`, so **60 seconds is the maximum, not the minimum**; the loop additionally never sleeps less than one second. |
| `SL_MAX_FILE_SIZE_MB` | 5 | Largest Slack attachment the agent will download. |
| `TG_CHAT_ID` | `""` | Telegram chat ID. Empty means auto-bind after the first valid inbound message. |
| `TG_POLL_TIMEOUT` | 20 (seconds) | Telegram long-poll timeout. |
| `WS_URL` | `""` | WebSocket endpoint (`ws://` or `wss://`). Required when `commchannel=websocket`. |
| `WS_TOKEN` | `""` | Bearer token sent as `Authorization: Bearer <token>`. |

`commchannel` selects which channel is started, not which ones are loaded: every channel listed in [`config/plugins.yaml`](/config/plugins.yaml) is imported at startup regardless of this value.

Channel credentials are passed as plain environment variables, without the `OMEGACLAW_` prefix, so that they stay outside the agent's own parameter space:

| Environment variable | Meaning |
|---|---|
| `TG_BOT_TOKEN` | Telegram bot token (from BotFather). |
| `MM_BOT_TOKEN` | Mattermost bot token. |
| `SL_BOT_TOKEN` | Slack bot token (`xoxb-...`). |
| `OMEGACLAW_AUTH_SECRET` | Secret the channel owner sends as `auth <secret>`. |
| `TEST_SERVER_IP` | Host address of the mock controller. Required by both the `test` channel and the `Test` provider; neither registers without it. |

## Plugins

| Parameter | Default | Meaning |
|---|---|---|
| `pluginWorkflowInstructionsDir` | `<project root>/plugins/workflow/instructions` | Directory holding the available workflows. |
| `pluginWorkflowMemoryDir` | `<memoryDirectory>/workflow_space` | Working directory used while a workflow is active. |

| `openClawAgent` | `main` | Which OpenClaw agent to address. |

There is no single switch that turns plugins off. A plugin runs if, and only if, it has an entry in `config/plugins.yaml`.

## Command-line overrides

Any `configure`d parameter can be overridden at startup. The agent is launched through `run.sh`, which comes from PeTTa; there is no `metta` binary in this repository.

```bash
sh run.sh run.metta provider=Anthropic model=claude-opus-4-8 commchannel=mattermost
```

Slack:

```bash
SL_BOT_TOKEN=xoxb-... sh run.sh run.metta commchannel=slack SL_CHANNEL_ID=C0123456789
```

WebSocket:

```bash
sh run.sh run.metta commchannel=websocket WS_URL=wss://chat.example.com/agent WS_TOKEN=...
```

When running in Docker, pass the same parameters through `scripts/omegaclaw` instead; it assembles the argument list and adds the ones the container needs.
